# Публикация JmacFoundation

Код уже находится в https://github.com/IlliaKunin/JmacFoundation. Для общей таблицы нужны база PostgreSQL и размещение приложения в Streamlit Community Cloud.

## 1. Создать базу в Supabase

1. Открой https://supabase.com/dashboard и войди в свой аккаунт.
2. Создай новый проект (**New project**) с названием `JmacFoundation`. Выбери организацию и регион, задай и сохрани пароль базы данных. Это отдельный пароль, не пароль входа в аккаунт.
3. Дождись создания проекта.
4. Нажми **Connect**, выбери строку подключения **URI** и **Session pooler**. Скопируй строку целиком из панели; адрес сервера и имя пользователя не нужно придумывать.
5. Замени `[YOUR-PASSWORD]` в строке на пароль базы. Если в пароле есть специальные символы URL, они должны быть URL-кодированы. Добавь `?sslmode=require`, если параметров ещё нет; если они есть, добавь `&sslmode=require`.

Session pooler подходит для подключения по IPv4. Приложение создаст служебную таблицу самостоятельно в закрытой схеме `jmac_private`; создавать столбцы вручную не нужно. Нужна PostgreSQL URI, а не Supabase Project URL, anon key или service-role key.

Документация: https://supabase.com/docs/guides/database/connecting-to-postgres

## 2. Перенести текущие результаты

До запуска приложения для других пользователей добавь строку подключения в локальный `.env`:

```dotenv
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/postgres?sslmode=require
```

Используй свою строку из Supabase. Затем в терминале проекта выполни:

```powershell
.\.venv\Scripts\python.exe manage_storage.py import
```

Импорт копирует текущие CSV, историю и контакты в общую базу. Существующие данные базы не перезаписываются, локальные файлы сохраняются. Если нужна пустая таблица, импорт можно пропустить.

Не отправляй пароль или полную строку подключения в чат и не добавляй `.env` в GitHub.

## 3. Опубликовать приложение

1. Открой https://share.streamlit.io и войди через GitHub.
2. Нажми **Create app**, выбери размещение из GitHub.
3. Укажи репозиторий `IlliaKunin/JmacFoundation`, ветку `main` и основной файл `app.py`.
4. В **Advanced settings** выбери Python 3.12 или новее.
5. В поле **Secrets** добавь три значения, заменив подсказки своими данными:

```toml
TAVILY_API_KEY = "твой ключ Tavily"
GROQ_API_KEY = "твой ключ Groq"
DATABASE_URL = "твоя PostgreSQL URI из Supabase"
```

Настройки должны быть на верхнем уровне, без секции в квадратных скобках. Строка базы должна совпадать с той, которую использовали для импорта.

6. Нажми **Deploy**. После запуска получишь ссылку приложения.
7. В настройках **Sharing** выбери публичный доступ или доступ определённым людям.

Документация: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy

## Что будет с общей таблицей

Результаты всех пользователей накапливаются в одной базе. Правки и удаления тоже общие. Свежие данные видны при открытии или обновлении приложения. После обновления кода на GitHub данные остаются в Supabase.

CSV на твоём компьютере автоматически не синхронизируются с облаком. Для актуального файла, открывающегося в Excel, выполни:

```powershell
.\.venv\Scripts\python.exe manage_storage.py export --output exports/sellers.csv
```

## Проверка после размещения

Открой приложение, запусти поиск одной статьи, затем открой ту же ссылку в другом браузере. Там должны появиться сохранённые результаты. Измени одну ячейку через **Save changes** и проверь её во втором браузере после обновления страницы. До подключения реальной базы проверка доступа к Supabase и эта проверка размещения ещё не выполнены.
